# Instagram Downloader Bot

A serverless Telegram bot hosted on Vercel that downloads Reels, Posts, Stories, and Carousels via a Cloudflare Workers API backend.

---

## 🛠️ Required Environment Variables

You must add this variable in your **Vercel Dashboard -> Project Settings -> Environment Variables** for the bot to function:

| Key | Value | Description |
| :--- | :--- | :--- |
| `BOT_TOKEN` | `123456:ABC...` | Your Telegram Bot Token obtained from [@BotFather](https://t.me/BotFather) |
